# 哈希页操作流程

哈希页按「选输入 → 选算法 → 计算 → 看结果」四步排列，每步带编号与完成标记；
步骤之间不做隐式跳转，任何一步缺失都只是该步未打勾，不会悄悄用别的数据代替。

## 第 1 步 · 选择输入

| 入口 | 行为 |
|---|---|
| 选择文件 | 调用系统多选文件对话框，一次可跨目录选多个文件 |
| 选择文件夹 | 调用系统目录选择器，随后询问是否包含子文件夹 |
| 清空 | 丢弃当前条目与报告，回到未选择状态 |

跨目录多选时，引擎只哈希选中的那些文件：root 取它们共同的父目录，
路径以 root 相对名提交。同目录里没被选中的文件不会进结果。

平台没有提供选择器（例如精简的桌面环境）时会自动回退到手工路径输入框，
不会因为缺少插件而完全无法选文件。

## 第 2 步 · 选择算法

算法按钮的 ID 必须与引擎注册表一致（见 [algorithm-registry.md](algorithm-registry.md)），
否则整批请求会被判 `invalid_request`。至少保留一个算法，取消到只剩一个时会被忽略。

## 第 3 步 · 开始计算

计算期间可取消；取消后未完成的条目记为 skipped，而不是被当成删除。
一次性读取同时算出全部已选算法，不做多轮读盘。

## 第 4 步 · 查看结果

条目卡片展开显示每个算法的完整摘要，可选中文本或点右侧按钮复制。
结果区提供 CSV 与 JSON 导出，导出的内容与界面显示一致。
