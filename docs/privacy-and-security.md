# 隐私与安全

## 截断哈希不是安全摘要

- 文件名中的后缀是"便利比对 token"，默认 5 位十六进制，碰撞概率随批量规模上升。
- 报告同时保存完整哈希与截断后缀；**对比永远使用完整哈希**。
- 截断后缀不得用于安全校验、完整性证明或密码学用途。

## 算法安全语义

| 算法 | 安全定位 |
|---|---|
| MD5 / SHA-1 | 已被密码学攻破，禁止用于安全校验 |
| SHA-224/256/384/512、SHA3、BLAKE2、BLAKE3 | 密码学哈希 |
| XXH3 / XXH64 | 非密码学快速哈希 |
| CRC32 / CRC32C | 错误检测校验和，不是内容摘要 |

UI 与非加密算法写名时必须显示警告。

## 报告导入不可信

- 拒绝未来 schema_version。
- 限制条目数（2,000,000）与文件字节数（512 MiB）。
- 路径校验：拒绝绝对路径、反斜杠、NUL、逃逸 root 的 .. 段。
- 拒绝未声明算法、长度不匹配的哈希、无哈希的 ok 条目。

## CSV 公式注入

- CSV 导出默认不做 Excel 公式转义；导出对话框提供"公式注入防护"选项。
- 启用时以 = + - @ 开头的单元格前置单引号。
- 默认 UTF-8 无 BOM；Excel 兼容 BOM 为可选。

## 路径脱敏

- 报告默认记录相对 root 路径；platform_meta（URI / bookmark）仅用于审计，不参与对比 key。
- 分享报告前，用户应确认 root 与相对路径不泄露敏感信息。
- 日志保存在 app 私有目录，不写入外部存储。

## 权限最小化

- Android：SAF 按用户选择授权，持久化 URI permission 仅用于撤销。
- iOS：security-scoped bookmark 仅在需要跨会话撤销时保存。
- 桌面：仅访问用户显式选择的文件/目录。

## 重命名安全

- 默认不执行；勾选后仍先 dry-run 与冲突检测。
- 目标已存在默认不覆盖。
- 只读文件/无权限目录提前检测并标记。
- 撤销前逐文件检测移动/改动，冲突逐条报告，不强行覆盖。
